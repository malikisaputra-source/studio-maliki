Pengaturan AI

Studio tidak menyediakan AI. Sambungkan AI yang kamu punya; kunci disimpan hanya di laptop ini.

tampilan

Otomatis mengikuti mode gelap/terang laptopmu. Pemutar video & pratinjau tetap gelap agar warna hasil akurat.
Semua model di atas bertier gratis menurut aistudio.google.com/docs/pricing (13 Nov 2026). Kalau model pilihan sibuk, Studio otomatis mencoba model cadangan.
Langganan chat tidak termasuk kunci API, tapi bisa dipakai lewat CLI resminya: Claude Code (Claude Pro/Max) · Codex (masuk dengan akun ChatGPT) · OpenCode (sambungkan penyedia/langganan di OpenCode). Pemakaian memotong kuota langgananmu. Studio menghapus kunci API dari lingkungan supaya yang terpakai benar-benar langganan.

suara narator motion

VoxCPM2 dari OpenBMB (lisensi Apache-2.0): 30 bahasa termasuk Indonesia, suara jauh lebih natural, jalan di laptopmu. Unduhan pertama ±5 GB. Paling cepat di Mac Apple Silicon atau PC dengan GPU NVIDIA.
Wajib rekaman suaramu sendiri (atau pemilik suara yang memberi izin). Studio tidak menyediakan suara clone siapa pun.
